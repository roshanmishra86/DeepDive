## What’s new in v0.2.9

- Added the **Weekly Priorities** section to the Week Page, enabling structured weekly target outcomes and reviews.
- Introduced weekly outcome todo rows with rank indices, drag handles, outcome descriptions, priority badges, and target date selectors.
- Added direct workflow progress tracking (`Not started`, `In Progress`, `Done`) with visual status pills and status change menus.
- Supported quick-add creation for target priorities directly from the week view with custom outcomes, priority levels, and day targeting.
- Added edit mode with quick reordering, deletion, and selection from existing pending tasks.
- Modernized the Week Page footer layout with a two-column split: Weekly Priorities alongside stacked Time Allocation and Weekly Insights cards.
- Retained full compatibility with existing planner data, focus timer, sound library, and database schema.

## Notes

Existing planner data, tasks, templates, rituals, notes, timer state, archive,
and sound-library behavior remain fully compatible with this release.
