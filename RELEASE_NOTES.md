## What’s new

- Redesigned Today as a calm, editorial daily-planning workspace.
- Added compact summary metrics, category icons, and muted block colours.
- Added pointer-driven block reordering with live schedule previews.
- Added capped proportional block heights from 30 through 90 minutes.
- Moved Quick notes into the utility rail with a taller, scrollable editor.
- Refined the focus timer, navigation, music player, and shared visual system.
- Applied the DeepDive name consistently across the desktop application.

## Notes

Existing planner data, tasks, templates, rituals, notes, timer state, archive,
and sound-library behavior remain compatible with this release.
